# Приложение для анализа банковских операций

## Описание
- Загрузка и анализ банковских транзакций из Excel.
- Определение периода и суммарных трат по картам.
- Подсчёт кэшбэка и отображение топ-транзакций.
- Получение актуальных курсов валют через API apilayer.com.
- Получение цен акций через API financialmodelingprep.com.
- Генерация сводной информации с приветствием, курсами, акциями и основными тратами.
- Сервис "Инвесткопилка" позволяет копить через округление трат.
- Представлен инструмент для анализа расходов по дням недели за последние 3 месяца.

## Установка:
1. Клонируйте репозиторий
   ```
   git clone https://github.com/YuliyaSwan/BankOperationsKR1.git
   ```
2. Установите зависимости
   ```
   pip install -r requirements.txt
   ```
3. Установите Pytest
   ```
   poetry add --group dev pytest
   ```
4. Установите Code coverage для %-ки проверки кода
   ```
   poetry add --group dev pytest-cov
   ```
5. Установите Dotenv
   ```
   poetry add python-dotenv
   ```
6. Создайте .env файл и добавьте API-ключи:
   API_KEY_1=your_apilayer_key
   API_KEY_2=your_fmp_key
7. Пример *user_settings.json*:
  {
  "user_currencies": ["USD", "EUR", "CNY"],
  "user_stocks": ["AAPL", "GOOG", "TSLA"]
   }

2. **Сервис. «Инвесткопилка»** - модуль **services.py**.
   Пример использования: print(investment_bank("2018-05", transactions, 50)). Возвращает JSON с:
   - Выбранным месяцем.
   - Указанным лимитом.
   - Возможной суммой накоплений.
   
   Пример вывода JSON-ответа:
{
    "month": "2018-05",
    "limit": 50,
    "savings": 3740.2
}
   Тестируются:
   - Получение периода месяца.
   - Загрузка транзакций из Excel (используется мокающий подход).
   - Расчёт накоплений через округление.
   - Финальная функция investment_bank, которая возвращает корректный JSON.

3. **Отчеты. Траты по дням недели** - модуль **reports.py** - предоставляет инструмент для анализа расходов
по дням недели за последние 3 месяца. Отчет автоматически сохраняется в .json и логируется в app.log.
    Тесты покрывают:
   - Загрузку транзакций: проверка обработки дат, пустых значений, ошибок структуры.
   - Генерацию отчета spending_by_weekday: Проверка, что результат содержит все 7 дней недели.
Округление значений. Поддержка пустых входных данных. Логирование ошибок.
   - Декоратор save_report: Сохранение JSON-файла. Обработка ошибки при неверном типе результата.
Проверка логирования вызовов.
